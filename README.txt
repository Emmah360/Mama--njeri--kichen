SAVANNA BREW CAFÉ — WEBSITE PROJECT

Contents
- index.html, about.html, menu.html, gallery.html, contact.html
- css/style.css
- images/ (logo, hero, owner portrait, menu photos and eight gallery photos)

How to view
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Use the navigation to visit the other four pages.
4. Resize the browser to check the mobile layout.

Project requirements implemented
- HTML5 document structure and semantic page regions
- Shared header, navigation and footer on all five pages
- External stylesheet, CSS variables, Flexbox and CSS Grid
- Active-page navigation styling, hover/focus states and responsive media queries
- Menu tables with KES prices, gallery figures/captions, and labelled reservation form
- Relative image and page links, descriptive image alt text

Notes
- The reservation form uses a mailto action as a front-end demonstration. A real booking
  system requires a server-side form handler or booking service.
- The contact details and business story are fictional assignment content.
- The included image assets are illustrative café-themed images prepared for this project.
- Run the HTML and CSS through the W3C validators before final academic submission.
  No W3C validation certificate is included with this starter project.
